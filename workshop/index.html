Get started.

Install the Held in Common node on your own machine, add your profile, and share it to the workshop commons. Your data stays on your node.

1 · Download the app
macOS
Apple Silicon

M1 / M2 / M3 Macs. Then run the install line below.

Download .dmg →
Linux
x86 64-bit

Pick the format for your distro.

.deb (Debian / Ubuntu) .rpm (Fedora / RHEL) .AppImage (any distro)
2 · Set up
Install and open it

The build is unsigned, so macOS quarantines it. Paste this one line into Terminal — it clears the flag, copies the app to Applications, and launches it:

D=~/Downloads/Held-In-Common-macOS-AppleSilicon.dmg; xattr -c "$D" && M=$(hdiutil attach "$D" -nobrowse | grep -o '/Volumes/.*') && cp -R "$M/Held In Common.app" /Applications/ && hdiutil detach "$M" && xattr -cr "/Applications/Held In Common.app" && open "/Applications/Held In Common.app"

On Linux, install the package or mark the AppImage executable and run it.

Start your node

Launch the app and click Start the node. It runs locally at http://localhost:8080.

Add your profile

Fill in your bio and upload a photo. This is yours — it lives only on your node until you share it.

Share to the commons

In Share to a commons the workshop address is pre-filled — just confirm it and share. Your signed profile appears in the directory as Federated.
